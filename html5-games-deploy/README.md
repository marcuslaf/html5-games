# HTML5 Games

**Coleção de jogos clássicos feitos com HTML5, CSS3 e JavaScript puro. Sem frameworks, sem dependências externas — apenas código puro e diversão.**

**Collection of classic games built with pure HTML5, CSS3, and JavaScript. No frameworks, no external dependencies — just pure code and fun.**

## Jogos | Games

### 🐍 Snake Game
**Controle uma cobra que cresce ao comer. Evite bater nas paredes e em si mesma!**

**Control a snake that grows as it eats. Avoid hitting the walls and yourself!**

- Setas ou WASD para mover | Arrows or WASD to move
- ESPAÇO para pausar | SPACE to pause
- Sistema de pontuação | Scoring system

### 🧱 Breakout Game
**Destrua todos os tijolos com uma bola e uma barra. Cada cor vale pontos diferentes!**

**Destroy all bricks with a ball and a paddle. Each color is worth different points!**

- Mouse ou setas/WASD para mover | Mouse or arrows/WASD to move
- ESPAÇO para pausar | SPACE to pause
- 3 vidas com sistema de pontos | 3 lives with scoring system

## Funcionalidades | Features

- Controles responsivos (mouse + teclado) | Responsive controls (mouse + keyboard)
- Efeitos visuais com glow e sombras | Visual effects with glow and shadows
- Sistema de pausa | Pause system
- Tela de vitória e game over | Win and game over screens
- Botão voltar ao menu | Back to menu button
- Layout responsivo | Responsive layout
- Zero dependências externas | Zero external dependencies
